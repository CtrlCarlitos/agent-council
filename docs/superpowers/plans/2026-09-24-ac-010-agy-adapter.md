# AC-010 Agy Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the AC-006 adapter contract for the installed Antigravity CLI (`agy`, verified 1.2.9) as a process-per-turn, stdin-only stream-json contributor: provider-free creation and pre-transmission `init` verification, a kernel-sealed execution image verified inside the executor before any output is trusted, a shared-home production-eligibility gate whose coverage derives from a pinned tool-coverage map, native auto-denial surfaced as structured `tool_denied` events with required-tool verification, SIGINT-based bounded cancellation, and advisory-only durable state — all fail-closed until the operator-authorized evidence path exists.

**Architecture:** `internal/adapter/agy` provides `AgyAdapter` (AC-006 contract), `stream.go` (strict NDJSON event decoding + stderr markers), `profile.go` (`ValidateAgyHarness`, coverage/denial-map evidence), `coverage.go` (map-derived cprot-v2 coverage), `verification.go` (required-tool/denial correlation), `identity.go` (pdig-v1 reuse), and the `agytest` test-only construction package. `internal/adapter/execpolicy` gains the sealed-image launch (`memfd` + exec-stop + `/proc/<pid>/exe` verification inside `Start`). `internal/adapter/evidence` becomes the shared evidence-root reader (moved out of `codex`). `internal/storage` owns migration v7, cprof-v4, and the agy transitions. `internal/service` owns wiring, birth, attestation recording, resolution, queue-time required-tools validation, and the evidence script.

**Tech Stack:** Go 1.25.0 (`golang.org/x/sys/unix` is already a transitive dependency for `memfd_create`/`fcntl` seals/`ptrace`; confirm with `go list -m all | grep x/sys` and add explicitly if absent — no other new deps), AC-005 `PolicyExecutor`/`workspace`, AC-006 `adapter`, AC-004 storage transitions, `crypto/sha256`.

Evidence: `docs/superpowers/evidence/ac010-agy-installed-interface-research.md`, `ac010-agy-init-1.2.9.json`, `ac010-agy-plugins-1.2.9.json`, `SHA256SUMS-ac010`.

## Global Constraints

- No provider calls in CI; the fixture `agy` executable replays recorded NDJSON. Native execution only in the operator-invoked evidence script.
- **Gate 1 boundary (binding):** no authenticated `agy` invocation until Gate 1 closes (Tasks 1–5 fixture-only).
- Production eligibility requires a valid cprot-v2 attestation (contributor-scoped table) COVERING `expected_tools` ∩ coverage map, an empty MCP/plugin inventory, the frozen `permission_mode ∈ {request-review, strict}`, a linux/unix platform, and a sealed-image launch; `agytest` is the only pre-attestation construction path.
- Every launch through `PolicyExecutor.Start` with `SealedImage` set — never `os/exec`, never a shell, never the operator's alias. Frozen argv exactly: `--print= --input-format stream-json --output-format stream-json --disable-slash-commands --model <frozen> --print-timeout <backstop>s --log-file <launch log> [--mode <frozen>] [--sandbox] [--conversation <id>]`. Forbidden anywhere: `--dangerously-skip-permissions`, `-c/--continue`, `-i/--prompt-interactive`, `--remote-control`, `--add-dir`, `--project`, `--new-project`, `install`, `update`, `mic-serve`.
- `HOME` is never overridden for authenticated runs; the keyring/credential file is never read, copied, or linked; `settings.json`, `hooks.json`, `mcp_config.json` are never written.
- The prompt is one NDJSON line `{"event":"user","message":{"content":"<text>"}}` on stdin, written ONLY after `init` verification; the first written byte is the only ambiguity boundary. Exit codes never classify; `result` does.
- `init.conversation_id != requested` ⇒ `ErrConversationDrift` (prompt never written, orphan id recorded). Unknown `event`/`step_type`, malformed lines, stderr `[agy] print timeout` / `ignoring unsupported stream input message event` ⇒ Uncertain (never terminal success).
- No protected-evidence upgrade, no redispatch (`launch_count ≤ 1`); every started attempt without an in-life `result` stays Uncertain until a controller disposition.
- Platform: production construction refuses any frozen platform other than linux/unix; sealed launch and exec-stop are Linux-only (`//go:build linux`); windows/darwin vet+compile stay green with typed refusals.
- Crash-boundary rule: every durable transition in spec §3.11 gets a crash-gap test.
